# HomePro Technician Connect

ระบบบันทึกและจัดการข้อมูลลูกค้าช่างและลูกค้าบ้าน (Technician & Homeowner Management System) ออกแบบมาเพื่อช่วยทีมงาน HomePro ในการติดตามงานช่าง หน้างาน เอกสารไฟล์ และความสัมพันธ์ระหว่างช่างกับลูกค้าบ้าน โดยใช้ Google Sheets เป็นฐานข้อมูลหลัก และ Google Drive สำหรับเก็บไฟล์เอกสาร/รูปภาพ

---

## 🚀 สถาปัตยกรรมระบบ (Architecture)

ระบบถูกแบ่งออกเป็น 2 ส่วนหลัก:
1. **Frontend (`index.html`):** หน้าเว็บแอปพลิเคชัน Single-Page สไตล์ Modern Dashboard พัฒนาด้วย Tailwind CSS, Chart.js และ SheetJS ทำหน้าที่แสดงผล จัดการฟอร์ม ค้นหา และสื่อสารกับเซิร์ฟเวอร์ผ่าน HTTP POST (`fetch`)
2. **Backend (`Code.gs`):** Google Apps Script ทำหน้าที่เป็น REST-like API จัดการความปลอดภัย (Session Token & RBAC), ตรวจสอบข้อมูลซ้ำ, ควบคุม concurrency ด้วย `LockService`, บันทึกข้อมูลลง Google Sheets และจัดการอัปโหลดไฟล์ไปที่ Google Drive อัตโนมัติ

---

## 🛠️ ฟีเจอร์หลักของระบบ

- **จัดการลูกค้าช่าง (Technicians):** บันทึกข้อมูลช่าง ประเภทงาน พื้นที่ให้บริการ และสถานะ Active/Inactive
- **จัดการลูกค้าบ้าน (Homeowners / Homecard):** ป้องกันข้อมูลซ้ำด้วยเลข Homecard และบันทึกข้อมูลติดต่อ
- **จัดการหน้างาน & ไฟล์ (Sites & Drive Storage):** สร้างหน้างานผูกกับลูกค้าบ้าน และอัปโหลดไฟล์/รูปภาพ (จำกัดขนาด 10MB) แยกโฟลเดอร์บน Google Drive อัตโนมัติ
- **ช่างสร้างบ้านให้ลูกค้า (Assignments):** เชื่อมโยงความสัมพันธ์ระหว่างช่าง ลูกค้าบ้าน และหน้างาน พร้อมบันทึกมูลค่างานและปีที่สร้าง (พ.ศ.)
- **ค้นหาความสัมพันธ์ (Relationships Explorer):** ค้นหาแบบ 360 องศา ดูว่าช่างคนนี้มีลูกค้าบ้านใครบ้าง หรือลูกค้าบ้านคนนี้มีช่างคนไหนมาสร้างบ้านให้
- **ระบบผู้ใช้งานและสิทธิ์ (RBAC):** กำหนดสิทธิ์ 4 ระดับ ได้แก่ *Super Admin, Manager, Sales Staff, Viewer* พร้อมระบบเข้ารหัสรหัสผ่าน (SHA-256 + Salt)
- **รายงาน & ส่งออก Excel (Reports & Export):** ส่งออกข้อมูลทั้งหมดหรือรายตารางเป็นไฟล์ `.xlsx` ได้ทันที
- **Audit Logs:** บันทึกประวัติการกระทำทุกอย่างในระบบ (เพิ่ม, แก้ไข, ลบ, อัปโหลด, เข้าสู่ระบบ)

## ⚙️ วิธีการติดตั้งและตั้งค่าระบบ (Setup Guide)

### 1. ตั้งค่าฝั่ง Google Apps Script (Backend)
1. สร้าง **Google Sheet** ใหม่ขึ้นมา 1 ไฟล์
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. คัดลอกโค้ดจากไฟล์ `Code.gs` ไปวางแทนที่โค้ดเดิมทั้งหมด
4. (ทางเลือก) หากต้องการระบุ Google Sheet เจาะจง ให้ใส่ ID ลงในตัวแปร `SPREADSHEET_ID` (ส่วนระหว่าง `/d/` และ `/edit` ใน URL ของ Sheet)
5. กำหนดรหัสผ่านสำหรับติดตั้งระบบคนแรกที่ตัวแปร `SETUP_CODE` (ห้ามใช้ค่าเริ่มต้น `CHANGE-ME`)
6. กด **Deploy > New deployment (การใช้งานใหม่)**:
   - **Select type:** Web app
   - **Execute as:** Me (ตัวคุณเอง)
   - **Who has access:** **Anyone (ทุกคน)** *(สำคัญมาก เพื่อให้เว็บภายนอกเรียกใช้งานได้)*
7. คัดลอก **Web App URL** (ที่ลงท้ายด้วย `/exec`) เก็บไว้

### 2. ตั้งค่าฝั่งหน้าเว็บ (Frontend)
1. เปิดไฟล์ `index.html` ด้วยโปรแกรม Text Editor (เช่น VS Code หรือ Notepad)
2. ค้นหาตัวแปร `API_URL_CONST` ที่ส่วนบนของแท็ก `<script>`:
   ```javascript
   const API_URL_CONST = 'https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec';
   ```
3. นำ **Web App URL** ที่คัดลอกมาจากขั้นตอนการ Deploy มาวางแทนที่ `'https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec'`
4. บันทึกไฟล์ `index.html`

### 3. การเริ่มต้นใช้งานครั้งแรก
1. เปิดไฟล์ `index.html` ผ่าน **Local Server** (เช่น ใช้ Extension *Live Server* ใน VS Code) หรือรันผ่านเซิร์ฟเวอร์จำลองบนเครื่องเพื่อหลีกเลี่ยงข้อจำกัด CORS ของเบราว์เซอร์
2. ระบบจะพาไปหน้า **"ตั้งค่าผู้ดูแลระบบคนแรก"** อัตโนมัติ
3. กรอกรหัสตั้งค่า (`SETUP_CODE` ที่ตั้งไว้ใน Apps Script), ชื่อผู้ใช้, ชื่อที่แสดง และรหัสผ่าน (อย่างน้อย 8 ตัวอักษร) แล้วกดสร้าง
4. เมื่อเข้าสู่ระบบสำเร็จ ระบบจะทำการสร้างโครงสร้างชีตและโฟลเดอร์บน Google Drive ให้อัตโนมัติ พร้อมใช้งานทันที!

## 🔒 ความปลอดภัยและข้อควรระวัง
- **CORS & Fetch:** การเรียกใช้งานจากเครื่อง local หรือ Domain อื่นใช้การส่งผ่าน POST แบบ `text/plain` เพื่อความเข้ากันได้กับ Google Apps Script Web App
- **Session Timeout:** Session Token มีอายุการใช้งานสูงสุด 6 ชั่วโมงตามขีดจำกัดของ `CacheService`
- **Rate Limiting:** ระบบมีกลไกป้องกันการสุ่มรหัสผ่านผิดเกิน 5 ครั้ง โดยจะทำการล็อกชั่วคราว 15 นาที
